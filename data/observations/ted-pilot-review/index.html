Review steps

  1. Identify the source event, track, and respondent using the source attribution and conversation, then verify their association with the selected audio/video.
  2. Check continuity and camera motion. A visible smile is distinct from audible laughter. A hand outside the frame is unobservable.
  3. For a pre-answer pause, listen to the actual question ending and first answer sound. Leave the value unknown if editing or clock alignment makes it unknowable.
  4. Fill the review template with the reviewer type, evidence note, checks you actually completed, and source-clock annotations.
  5. Import the annotations with python -m tools.observations review. Only accepted human observations from training events can enter the exported runtime index.

Allowed annotation kinds: visible_smile, audible_laughter, head_nod, head_tilt, hand_wave, hand_emphasis, hand_unobservable. Each annotation needs start_seconds, end_seconds, phase (listening/speaking/unknown), and observable (true/false). Hand annotations also need side (left/right/both). Set acoustic boundaries only after the corresponding listening and continuity checks.

Voice naturalness and similarity are evaluated separately using the existing generated-speech listening bundle. This page does not infer voice quality from ASR or source geometry.
