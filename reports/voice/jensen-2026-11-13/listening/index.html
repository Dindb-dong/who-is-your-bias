How to read the measurements

ASR is an independent unprompted recognizer. WER measures normalized word errors; CER measures normalized character errors. The number case uses literal scoring: the recognizer wrote 9.30, 12 and 24 where the input used words.

WavLM values are raw cosines, averaged within each of four source events and then across events. They are not resemblance percentages or human ratings. Source references were exposed to training; there is no held-out-event or impostor calibration. Changes are mixed and do not establish an overall improvement.

Request times describe one ordered CPU run. The first request in each condition includes cold model loading. Waveform lengths and cache state differ, so the timings do not establish a speedup. The complete evaluation report preserves exact results.
