# Generated Jensen speech comparison

Open [index.html](index.html) locally after downloading this directory. It plays all eight exact generated WAVs without external scripts or services. GitHub displays the HTML source; use a local browser for the audio controls.

These are **AI-generated research simulations** from an unpromoted candidate experiment. They are not recordings of Jensen saying the test sentences. The page shows machine diagnostics; no human ratings have been entered.

The base and adapted conditions share the fixed text, source reference, generation settings and seed. The adapted condition actually loaded the verified 16-update checkpoint. [manifest.json](manifest.json) records the exact preserved waveform hashes and measured metadata. The [full evaluation](../evaluation.json) and [method guide](../../../../docs/jensen-voice-adaptation.md) explain preparation, learned weights, ASR, WavLM scores and limits.

Only the eight generated evaluation WAVs are included here. Original source/reference audio, full source transcripts, and model weights are not published in this directory. The private blind listening bundle remains unrated and is separate from this labeled comparison page.
